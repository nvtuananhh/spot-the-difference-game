Spot It! Twin Pictures is a complete, original spot-the-difference game drawn entirely in code: three hand-painted scenes (Sunny Garden Cottage, Harbour at Dusk, Starlit Library), 21 planted differences, limited hints, scoring with mistake penalties, a countdown timer, pause, restart, and full keyboard play with a mirrored reticle — all offline, with no images, fonts or network requests, and sounds made only with WebAudio oscillators.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
